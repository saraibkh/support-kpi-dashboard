# Project Summary — Customer Support Performance Dashboard

I created this project to practice customer support reporting and KPI tracking.

The project focuses on organizing ticket data, tracking response and resolution activity, and preparing basic reporting insights for support operations.

## What I worked on
- Organized customer support ticket records
- Tracked ticket status, category, and priority
- Calculated response and resolution metrics
- Reviewed CSAT-related reporting
- Wrote SQL queries for support performance analysis

## Why this project matters
Customer support teams rely on reporting to understand workload, response speed, and service quality. This project shows practical KPI reporting using a simple structured dataset.
