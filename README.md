# Customer Support Performance Dashboard

## Overview
This project analyzes customer support ticket activity using a sample dataset.  
The focus is on monitoring response time, resolution time, ticket status, and customer satisfaction.

## Business Question
How can customer support performance be tracked to improve response visibility, resolution follow-up, and service quality?

## Dataset
The dataset contains sample support ticket records with:
- Ticket ID
- Opened date
- Support channel
- Category
- Priority
- Status
- First response hours
- Resolution hours
- CSAT score

## KPIs Tracked
- Total tickets
- Resolved tickets
- Open tickets
- Escalated tickets
- Average first response time
- Average resolution time
- Average CSAT score
- Tickets by category and channel

## Tools Used
- Excel / Google Sheets
- SQL
- CSV dataset

## What I Practiced
- Customer support analytics
- KPI reporting
- SQL filtering and aggregation
- Dashboard planning
- Data organization
- Operational performance tracking

## Main Insight Examples
- Identify categories with higher escalation rates.
- Track response time by priority level.
- Monitor average resolution time by channel.
- Understand the relationship between resolution speed and CSAT.
